# Base de Conocimiento del Cliente

Coloca en esta carpeta cualquier archivo de información específico de este cliente:
- Catálogo de productos o servicios (`catalogo.md`, `servicios.txt`)
- Lista de precios (`precios.txt`, `tarifas.md`)
- Preguntas frecuentes (`faq.md`, `preguntas_frecuentes.txt`)
- Políticas de garantía, envío o devolución (`politicas.txt`)
- Menú o carta del restaurante (`menu.txt`)

### Formatos soportados
- Archivos de texto plano (`.txt`, `.md`, `.json`, `.csv`)

### ¿Cómo funciona?
El motor de Tabersil Chatbots lee automáticamente todos los archivos presentes en esta carpeta y se los entrega a Gemini AI como fuente de verdad. El agente responderá a tus clientes utilizando estos datos sin necesidad de entrenar modelos ni programar nada.
